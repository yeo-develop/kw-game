# 스토어 1위 전략 (2026-11-10)

> 목표 정의: **스팀 한국 지역 일간 차트**(최고 판매·인기 신작) 1면 + 평가 "매우 긍정적". 글로벌 차트는 영어판 뒤의 2차 목표.
> 무기는 세 가지: (1) 제목 그대로의 클립 순간, (2) 판이 끝날 때마다 퍼지는 결과 카드·오늘의 판, (3) 28일을 몇 번이고 다시 돌게 하는 엔딩 수집·도전과제·난이도.
> 검증은 늘 `./unity simtest balance 300` 띠 안에서 (docs/V4.md §7). 감으로 수치를 바꾸지 않는다.

## 1. 포지셔닝

- **한 줄 훅**: "레버리지 롱 잡고 알바 갔는데, 편의점 계산대에서 청산 알림이 왔다. 여친은 공동 채무자다."
  - 영문 초안: "Go long, go to work, get liquidated at the register. Your girlfriend co-signed the loan."
- **비슷한 게임엔 없는 3가지**
  | 차별점 | 비교 | 코드 |
  |---|---|---|
  | 일하는 동안 **실시간으로 청산**된다 (안전한 돈 vs 위험한 돈이 같은 시간을 두고 충돌) | STONKS-9800 은 매매가 본 게임 | `GameSim.Realtime.cs` `rtLiq` + §3 ⑦ 경보 |
  | 여친이 **공동 채무자**이고 내 돈에 손을 댄다 (돌발 매수·아침 부탁·숨은 욕심·금고 털기 루트) | 니디걸은 한 사람을 돌보는 게임 | `GameSim.V4.cs` |
  | **진짜로 읽어야 하는 장** (국면 순서 무작위 · 가짜 속보 되돌림 · 주말 갭 · 이자일 급매) → 개그 게임인데 실력이 숫자로 남 (pro 52% · casual 6%) | 병맛 VN 은 시스템이 없음 | `V4_SCEN`, `planNext` |
- **타깃**: ① 주식·코인 해 본 20~30대 (곱버스·원양어선·한 방이 설명 없이 통함) ② 니디걸·멘헤라 장르 팬 (일본 잠재력) ③ 한국 병맛 인디 스트리머 시청자.
- **태그 (상위)**: Simulation · Dark Comedy · Funny · Multiple Endings · Choices Matter · Dating Sim · Economy · Trading · Time Management · Life Sim · Replay Value · Visual Novel · 2D · Anime · Short. **피함**: Gambling (노출 손해 + 심의).
- **가격**: ₩9,500 (≈ $7.99), 출시 할인 10~15%. 한 판 1~2시간 × 엔딩 매트릭스 · 2부 · 난이도 = 4~8시간.
- **한국어 단독 출시로도 차트에 오르는 이유**: 한국 지역 차트는 경쟁 규모가 작아 첫 48시간 리뷰가 몰리면 1면에 들어감. 밈(사채·원양어선·주갤)은 번역이 안 되는 대신 국내 바이럴 밀도가 높음. 치지직·SOOP·유튜브에 "한국 병맛 인디" 수요가 꾸준함.

## 3. 이번 패스 구현 목록 (상태는 §6)

① **저장 안정성** — `SaveTests.FailedWritePreservesPreviousSave` 가 macOS 에서 늘 실패하던 것 수정 (테스트가 Windows 잠금 의미에 기대고 있었음). 저장 코드는 원자적 쓰기(임시 파일 → 교체 → 백업)가 이미 맞음.
② **메타 진행** — `MetaStore`(`Saves/meta.json`): 엔딩 수집 · 도전과제 18개 · 판 수 · 클리어 수 · 최단 클리어 · 최고 실현수익 · 최근 판 20개. 타이틀 "기록" 화면 (못 얻은 것은 ??? + 힌트), 엔딩 화면 "NEW 엔딩 / 도전과제 달성".
③ **결과 카드 + 판 코드 + 오늘의 판** — 엔딩 화면 결과 카드(엔딩·갚은 %·실현수익·청산·호감·최고 배율·판 코드·난이도) + 복사(데스크톱·WebGL). 새 게임에서 판 코드 입력(`KW-xxxx`) · "오늘의 판"(날짜 씨앗 → 같은 날엔 모두 같은 장).
④ **난이도 3단계** — `V4_DIFF`: 순한맛(이자 2% · 시작 현금 ×1.5 · 돌발 매수 ½ · 호감 감쇠 ½ · 같이 원양어선 문턱 완화) / 보통 / 매운맛(이자 4% · 시작 현금 ×0.7 · 알바 ×0.9 · 문턱 강화). 저장에 남고, 결과 카드·기록에 표시, 도전과제 "매운맛 클리어".
⑤ **인게임 설정** — 전체·배경음·효과음 음량, 글자 속도(느림·보통·빠름·즉시), 화면 효과 끄기, 읽은 대사 빨리 넘기기. PlayerPrefs 저장.
⑥ **첫 60초** — 코치 카드 9장 → 첫 결정 전 3장 + 기능을 처음 만날 때 1장씩. 2회차부터 오프닝 건너뛰기.
⑦ **알바 중 청산 경보** — 알바 칸에 레버리지 포지션이 청산가에 가까워지면 한 번 끼어듦: "몰래 폰 본다"(정리 가능, 일당 깎임·들킬 확률) / "참는다". 제목 그대로의 10초 클립.

## 5. 하지 말 것 (1~2인 팀)

1. 실시간 LLM 을 출시판 기능으로 내세우기 (서버비 · 지연 · 스팀 AI 고지 · 커뮤니티 반감) → 오프라인 생성 후 검수한 풀로. 기본값 꺼짐.
2. AI 생성 그림·소리 숨기기 → 고지하고, 캡슐 이미지는 사람이 손봄.
3. 숨긴 장소 되살리기 · 3부 · 새 캐릭터 · 풀 보이스.
4. 자체 온라인 순위표·서버 (오늘의 판은 로컬 기록 + 결과 카드로 충분, 필요하면 Steamworks 리더보드).
5. 채팅 투표 연동 · 스팀 전 모바일 포팅 (카지노 심의) · 실제 시세·종목명 · 코인 제휴.
6. 밸런스를 감으로 (봇 300판 띠 밖은 금지) · 턴 모드·골든 리팩터 · main 병합.
7. 언어 여러 개 동시 출시 · 위시리스트 1만 전 유료 광고.
