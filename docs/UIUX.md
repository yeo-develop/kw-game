# UI/UX 정리 — 무엇이 문제였고, 무엇을 바꿨고, 지금 화면은 어떤가 (2026-11-11)

> 요청: "지금 산재해있는 UI/UX 등의 개선점을 리스트업하고 나열/ 개선해" · "바뀐 UI 전부 반영해서 정리해놔"
> 순서: ① 독립 감사(화면 코드 전체 + 배포본 캡처 16장)로 33항목 → ② 파일 영역을 나눠 수정 → ③ 독립 코드 검토 → ④ 배포본(7e890f5)을 화면 없는 브라우저로 직접 돌려 확인 → ⑤ 거기서 나온 것 다시 수정.
> 글자 크기는 1920×1080 기준 px (720p 화면에선 0.667배).

| **폰 · 내 계좌** | 포지션 줄마다 **예약 손절·익절 칩**(장 보기 칸에서만) | 잡은 뒤에도 예약을 걸고 바꿈 |
| **알바 설명 카드** | 일당 · 난이도 · 한 줄 요약 · "일 시작" · **"다른 알바 고르기"** | 고른 뒤에도 취소 가능(시간 안 씀) · 글 덩어리 삭제 |
| **알바 미니게임** | 구석에 내 포지션 손익 + **"몰래 폰 보기"** → 포지션별 [정리] · [전부 정리] · [그냥 닫기] 창(여는 것만으론 비용 없음, 게임과 시세는 계속 흐름) | 한 번에 전부 정리되던 것 → 골라서 · 알바 중 청산에도 연출 |

| **퀵메뉴** (대사창 아래) | 장 보기 · 미래랑 놀기 · 외출 · 쉬기(왼쪽 색 띠) · 빚 갚기 · 대출 · **P 폰** · 도움말 · 설정 · 저장 · 타이틀 | 가짜 키 동그라미 삭제(P 만 진짜) · 폰이 열려 좁을 땐 못 누르는 타일을 빼고 줄바꿈 |
| **타이틀** | 이어하기 · 새로 시작 · 설정 · 기록 · 종료 / 난이도 설명 | 개발용 "LLM API 키" 버튼 숨김 · 난이도 설명을 풀어 씀 |

**공통 규칙** (새 화면을 만들 때도 이대로)
- 돈 손익 = 이익 빨강 / 손실 파랑(`UpDn`). 0 은 회색. **초록은 현금 · 완료 · 통과 전용.** 경고 · 빚은 주황.
- 글자 하한 18(읽는 본문 20). 버튼 부제는 본문의 0.85배.
- 금액: HUD · 정산 · 폰 · 미니 시세는 만 단위(100만 미만은 소수 한 자리: 18.7만). 돈을 내는 화면(납부 · 상환 · 대출 · 상점 · 카지노)은 원 단위.
- 용어: 스트레스(멘탈 ×) · 칸(시간대 ×) · 적중/빗나감(맞음/틀림 ×) · **유물**(유품 ×).
- 되돌릴 수 없고 큰돈이 걸린 조작은 두 번 누르기. 그 밖은 한 번.
- 글꼴에 없는 기호 · 이모지를 새로 쓰지 않음.
- 키: Space(대사 넘기기 / 장 보기 중 멈춤) · P 폰 · 1/2/4 속도(장 보기) · 숫자 = n번째 선택지 · Esc 닫기.

## 3. 배포본 실행 검수 (7e890f5, 화면 없는 브라우저 · 새 프로필)
타이틀 → 새로 시작(보통맛) → 유물 고르기(숫자 키) → 첫날 집 → 장 보기 → 폰 → 빗트코인 10배 롱 → 폰 닫기(P) → 그만 보기(두 번) → 외출 → 일하기 → 카페 → 미니게임 → 몰래 폰 보기 창 → 저녁 정산. 콘솔 에러는 로딩 때 502 응답 2건(주소 미확인, 진행엔 영향 없음)뿐.

거기서 나와 다시 고친 것:
| 본 것 | 조치 |
|---|---|
| 폰을 열면 퀵메뉴 오른쪽("도움말"부터)이 잘림 | 좁을 땐 지금 못 누르는 타일을 빼고, 그래도 넘치면 줄바꿈 |
| 폰을 열면 선택지 상자가 HUD 아랫부분(스트레스 · 버프)을 가림 — HUD 가 길어져서 | 폰이 열리면 상자를 HUD 아래로 내림 |
| 지도 목록이 잘리는데 "▼ 더 있음"이 안 뜸 | 스크롤 영역에 최대 높이를 직접 줌 |
| "이 사람 기록 기록 없음" | 문구 수정 |
| 유물 상자 설명이 제목을 되풀이 | 문구 수정 |
| 주문 바가 폰 높이의 절반쯤을 차지해 차트가 작아짐 | 장 보기 전용 화면(BLUEPRINT_V3 4단계)에서 해결 — 지금은 둠 |
