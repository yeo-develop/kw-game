## 1. 지금 화면 구성 (화면 개편 (가) 뒤 — `docs/UI_V2.md`)

> 아래 2~5절은 뼈대를 둔 채 결함을 고친 1단계 기록이다. 그 뒤 사용자가 "바뀐 게 없다 · UX가 너무 불편해"라고 해서 **뼈대 자체를 바꿨다**(상황마다 전용 화면 · 누를 곳은 한 곳 · 상태는 한 줄). 지금 화면은 이 표가 기준이고, 그림은 `docs/SCREENS.md`.

| 화면 | 구성 | 예전과 다른 점 |
|---|---|---|
| **상태 띠** (맨 위, 모든 화면) | 날짜 · 칸 / 빚 / 현금 / 순자산 / **이번 주 납부 N만 + 막대 + "현금 A / 납부 B" 또는 "다 모음 · 내면 N 남음" + D-n** / 스트레스 · 호감. 누르면 **상태 카드**(장 · 만기 · 목표 · 미래 부탁 · 납부 내역 · 몸과 마음 · 호감 버프 · 유물 · 도움말/설정/저장/타이틀) | 왼쪽 위 상태판(작은 글자 12줄)이 없어짐 |
| **집 — 하루 계획판** | 왼쪽 미래 + 말풍선, 오른쪽 "오늘" 판: 오전 · 오후 · 밤. **지금 칸**에 장 보기 · 미래랑 놀기 · 알바 4종(누르면 바로 설명 카드), **끝난 칸**엔 한 일 + 손익, **남은 칸**엔 그 칸의 성격. 아래 칩: 쉬기 · 빚 갚기 · 은행 · 카지노 · 복권소 · 한강공원 · 대출. "어제: …" 한 줄. 판 아래: P 폰 · 유물 · 도움말 · 설정 · 저장 · 타이틀 | 대사창 아래 퀵메뉴 · 오른쪽 위 미니 시세 · 외출 지도 화면이 없어짐. 알바까지 7번 → 2번 |
| **장 보기 — 트레이딩 데스크** (방을 덮는 전체 화면) | 띠: 시계 · 속도(Ⅱ 1x 2x 4x) · 현금 · 평가 · 납부 · **그만 보기**. 왼쪽 **종목 목록**(등락 · 주갤 온도 막대 · 거래량 배수 · 보유/잠김 배지) / 가운데 **큰 차트**(봉 + 거래량 막대, 12h/24h/48h) / 오른쪽 **분석가 칩 → 주문 패널**(금액 · 배율 · 청산 확률 · 증거금 상한 · 예상 미끄러짐 · 잠김 이유 · 결과 줄 · 버튼) **→ 내 포지션**(손익 큰 숫자 · 절반/전부 팔기 · 닫기 · 예약 칩) / 목록 아래 **미래 작은 창** / 차트 아래 **소식 띠**(속보 · 전조 · 설거지 · 발표 · 예약 · 청산 · 리포트 기한) | 폰 → 탭 → 종목 → 주문 바였던 매매가 한 화면에. 폰은 데스크 위에서 카톡 · 주갤 · 뉴스 · 수첩만 |
| **저녁 정산 — 한 장** | 왼쪽 미래(결과별 표정 · 한마디), 오른쪽 카드: 오전 · 오후 줄(한 일 + 손익) · 그 밖 · **오늘 합계** · 현금 A → B · 옮긴 돈 · 납부 막대 · 리포트 적중 · 들고 있는 포지션 · [밤으로] | 가운데 어두운 카드 → 한 장. 띠가 그대로 보임 |
| **이야기 · 이벤트 · 장소 · 관문 · 엔딩** | 배경 + 인물 + **아래쪽 선택지 상자**(번호 = 숫자 키). 대사창은 **대사가 나올 때만**. 장면의 배경(분식집 · 학교 정문)은 선택지가 뜬 뒤에도 유지 | "위에서 골라 줘"만 있던 빈 대사창이 없어지고 상자가 내려와 인물 얼굴을 안 가림 |
| **폰** (P) | 집: 증권(시세 · 차트·주문 · 내 계좌) · 카톡 · 주갤 · 뉴스 · 정보 수첩. 데스크 위: 증권 탭 없음 | 띠 아래부터 열림 |
| **알바** | 설명 카드(일 시작 · 다른 알바 고르기 = 계획판으로) → 미니게임. 구석 "몰래 폰 보기": 코인 [정리] · **주식 [팔기]** · [전부 정리](정리할 게 없으면 꺼짐) | 주식 줄 추가 |
| **알림** | 토스트 = 띠 아래 왼쪽(집 · 정산은 말풍선 왼쪽 폭) · 배너 = 띠 아래 가운데 · 데스크에선 둘 다 차트 머리 아래 · 카톡 팝업 = 집은 왼쪽 아래, 데스크는 차트 칸 왼쪽 아래 | 누를 곳을 안 가리는 자리 |
| **타이틀** | 이어하기 · 새로 시작 · 설정 · 기록 · 종료 / 난이도 설명 | 그대로 |
| **복학 통장** (스토리, 11-11) | 맨 위 띠엔 안 넣음(이미 꽉 참). **계획판 "오늘" 머리줄 오른쪽**과 **상태 카드 "돈" 묶음**에 한 줄("복학 통장 400만 · 등록 마감 D-n" / 모자라면 경고색 + 모자란 돈 / 등록 끝이면 초록). 통장이 모자라고 현금이 있으면 칩 줄에 **"복학 통장 채우기 (N만)"**(두 번 누르기 · 칸 안 씀). 납부 관문에 다섯째 선택지 **"미래 복학 통장을 깬다"**(팔 수 있는 보유분이 남아 있으면 잠김 + 이유). 같이 태운 칸 동안 데스크 종목 줄에 "미래 판돈" 배지 | 새로. 관문 선택지가 5개일 때만 줄 높이를 줄여 인물 얼굴을 안 가림 |

**공통 규칙** (새 화면을 만들 때도 이대로)
- 돈 손익 = 이익 빨강 / 손실 파랑(`UpDn`). 0 은 회색. **초록은 현금 · 완료 · 통과 전용.** 경고 · 빚은 주황.
- 글자 하한 18(읽는 본문 20). 버튼 부제는 본문의 0.85배.
- 금액: HUD · 정산 · 폰 · 미니 시세는 만 단위(100만 미만은 소수 한 자리: 18.7만). 돈을 내는 화면(납부 · 상환 · 대출 · 상점 · 카지노)은 원 단위.
- 용어: 스트레스(멘탈 ×) · 칸(시간대 ×) · 적중/빗나감(맞음/틀림 ×) · **유물**(유품 ×).
- 되돌릴 수 없고 큰돈이 걸린 조작은 두 번 누르기. 그 밖은 한 번.
- 글꼴에 없는 기호 · 이모지를 새로 쓰지 않음.
- 키: Space(대사 넘기기 / 장 보기 중 멈춤) · P 폰 · 1/2/4 속도(장 보기) · 숫자 = n번째 선택지(집에선 계획판의 지금 칸 카드 순서) · Esc 닫기(상태 카드 · 폰 · 설정).
- 금액 표기의 "HUD · 미니 시세"는 이제 상태 띠 · 계획판 · 데스크를 뜻한다.

## 3. 배포본 실행 검수 (7e890f5, 화면 없는 브라우저 · 새 프로필)
타이틀 → 새로 시작(보통맛) → 유물 고르기(숫자 키) → 첫날 집 → 장 보기 → 폰 → 빗트코인 10배 롱 → 폰 닫기(P) → 그만 보기(두 번) → 외출 → 일하기 → 카페 → 미니게임 → 몰래 폰 보기 창 → 저녁 정산. 콘솔 에러는 로딩 때 502 응답 2건(주소 미확인, 진행엔 영향 없음)뿐.

거기서 나와 다시 고친 것:
| 본 것 | 조치 |
|---|---|
| 폰을 열면 퀵메뉴 오른쪽("도움말"부터)이 잘림 | 좁을 땐 지금 못 누르는 타일을 빼고, 그래도 넘치면 줄바꿈 |
| 폰을 열면 선택지 상자가 HUD 아랫부분(스트레스 · 버프)을 가림 — HUD 가 길어져서 | 폰이 열리면 상자를 HUD 아래로 내림 |
| 지도 목록이 잘리는데 "▼ 더 있음"이 안 뜸 | 스크롤 영역에 최대 높이를 직접 줌 |

| 본 것 | 조치 |

| 목록이 넘쳐도 "▼ 더 있음"이 여전히 안 뜸 (스크롤은 됨) | 판정을 스크롤 뷰 내부 값 대신 화면 좌표로 |
