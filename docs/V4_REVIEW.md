## 2. 지배 전략 · 죽은 선택지
1. **무료 리포트가 엔진**: 하루 2개, 칸 안 씀, 상승 리포트 기대값 ≈ +16% vs 도박 기대값 0.98~0.99 → 도박·숨긴 장소는 돈벌이로 죽음.
2. **밤엔 놀기 > 쉬기** (쉬기가 나은 건 체력 5).
3. **호감이 의미 없음**: 감소 경로 거의 없음 + "하지 마" 부탁 3/5 은 가만있어도 +8 → 측정: pro 100 · casual 97 · work 99 (300판 평균). lonely 엔딩 ≈ 0.
4. **부탁이 공짜**: 코인 금지 = 새로 열 때만 걸림, 밤엔 집에 = 원래 밤엔 놀기.
5. **욕심이 안 보임**: 신호 60↑ 인데 털기 문턱 50, 문서(호감 60↑)와 코드(호감 85↑·욕심 50↑) 불일치.
6. **뉴스가 사후**: 칸 끝에 "헤드라인 → 결과" 로만 뜸 → 뉴스 보고 판단 불가.
7. **알바 하나로 수렴**: 직종 급여 같음, 상하차·마트는 체력만 더 듦. 메뉴 표시는 1만~10만인데 실제 12만~24만 (버그).
8. **정답 있는 이벤트**: 2부 김사장 고백(60% 빚 −40%, 실패 대가 멘탈만) · 리딩방(기대값 +30만) · 김사장 제안(기대값 0 동전).
9. 2부 이자 주 500만 → 알바로는 이자도 못 막음.

## 4. 수정 목록
**P1**
1. 뉴스를 칸 시작에 "속보"로 먼저 (가짜 뉴스 유지).
2. 국면 = 확률 (드리프트 낮추고 장별 뉴스 방향 편향, 장 카드 차트 아이콘 정답 공개 제거).
3. 주말 갭 (주말 국장 움직임을 쌓아 월요일 오전에) + 이자일 "전량 매도" 급매 손해.
4. 국장 매매·리포트는 장 보기 칸에서만 (코인은 어디서나).
5. 호감 감쇠 · 높을수록 덜 오름 · 하지 마 부탁 보상 절반 · "밤엔 집에" → "밤엔 나랑" · 코인 금지는 자정에 들고 있어도 어김.
6. 욕심 신호를 털기 문턱 −15 부터, 문서/코드 털기 조건 맞춤.
7. 알바 표시 급여 버그 · 직종별 배율 (상하차 ×1.4, 마트 ×1.2).
8. 정답 이벤트 고치기 (2부 김사장 실패 대가 · 리딩방 성공액 · 김사장 제안 기대값 음수).

**P2**: 엔딩 수집을 판 밖에 저장 · 알바 중 청산 경보 선택지 · 2부 국면 순서 뒤집기 · 만기 직전 카지노.

## 5. 반영 결과 (같은 날)
P1 1~8 전부 구현 (docs/V4.md §8). 측정 (`./unity simtest balance 300`, 사람 봇 pro·casual 추가):
- **호감이 갈림**: 평균 pro 71 · casual 64 · work 42 · gamble 22 · random 9 (전엔 다 ~100). lonely 엔딩이 pro 3% · casual 3% · gamble 7% 로 실제로 나옴.
- **실력 차이가 결과로**: pro(속보 매매 + 국면 타기 + 금요일 정리) 클리어 39% vs smart(리포트만) 31% vs casual 8% vs work 0%.
- **금요일 결정이 실제로 돈**: 봇이 주말을 들고 넘기다 이자일 급매(−20%)로 무너진 게 측정에서 먼저 드러남 → 금요일 정리하는 봇만 살아남음. 28일 만기가 일요일이라 26일까지 국장 정리 못 하면 주식이 묶임.
- **장 보기 칸이 살아남**: pro 행동 = 장 보기 43% · 알바 28% · 놀기 25%.
- **국면이 가격에 나옴** (`BAL_MKT=1`): 2장 대장코인 +50~70% · 4장 갓성 −10~24% · 곱버스 + .
- 남은 것: 털기 엔딩은 봇으론 0% (호감 85↑ + 욕심 50↑ 이 동시에 필요한 숨은 엔딩, V4Tests 로만 확인). P2 (엔딩 수집 저장 · 알바 중 청산 경보 · 2부 국면 뒤집기 · 만기 직전 카지노) 는 다음.
