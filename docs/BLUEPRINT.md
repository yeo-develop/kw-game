# 기획서 1장 — 핵심 루프 재설계 (초안 2026-11-10, 승인 전 · 코드 0줄)

> 방식: game-blueprint(코드 전에 기획서 1장 · 완료 기준 = 테스트 1:1 · 성능 상한 먼저) + self-check(읽지 말고 돌려서 확인 · progress 로그 · 전부 통과까지).
> 한 줄: **"오전에 잡고, 맡기고 알바 갈지 지켜볼지 고르고, 끝나고 폰을 깐다. 밤엔 그 결과를 들고 미래를 만난다. 7일마다 김사장이 더 큰 돈을 받으러 온다."**

## 0. 왜 다시 짜는가 — 실측 (봇 20판 추적 + 300판 밸런스, 11-10)

## ② 자원 · 경제
- 자원 4개: **현금 · 빚(주간 납부) · 스트레스 · 호감** (+ 숨은 욕심). 체력 삭제.
- 들어오는 돈: 알바(느리고 확실) · 현물(작은 우위) · 레버리지(우위 증폭, 청산 위험).
- 나가는 돈: 주간 납부 = 남은 빚 3% 이자 + 원금 분납 **200 → 500 → 900 → 잔액(1,400)**. 미리 더 내도 됨.
- 미납: 못 낸 만큼 다음 주로 넘어가고 10% 가산 · 증거금 상한 동결 · 김사장 방문 장면. **2주 연속 미납 = 원양어선.**
- 기둥 연결: 알바 점수 0.7↑ → 다음 칸에 움직일 종목 1개(방향 없음) / 장 결과 → 밤 장면 재료·욕심 / 호감 구간 → 버프.
- 화면의 주 목표: "이번 주 납부까지 N만 · D-n" 막대 + 순자산.

## ③ 압박 주체의 행동 (숫자)
- **김사장**: 7·14·21·28일 밤 수금. 요구액 약 290 → 584 → 970 → 잔액. 주 중 1회 안부 방문(고정 장면). 미납 반응은 ②.
- **시장**: 칸마다 속보 50% (가짜 30% · 되돌림). 장 보기 칸의 30% · 70% 지점에 중간 사건. 현물 하루 변동 ±3~8% · 코인 ±10~25% (`RT_VOL` 2 → 주식 1.2). 국면 시나리오 6종 유지.
- **미래**: 아침 부탁 1개. 대박이면 욕심 +, 청산이면 '싸운다/위로받는다' 선택. 돌발 매수 확률 = 욕심/200 유지.

## ④ 조작
- 마우스 중심. 속보에서 매수까지 2클릭 이내. 주문창에 손절·익절 슬라이더.
- 키: Space 진행 · P 폰(알바 중엔 '몰래 보기') · 1/2/4 속도. 알바 미니게임 키와 P 가 겹치지 않게.

## ⑤ 화면
HUD(납부 막대 · 순자산 · 호감) · 장 보기(차트 · 속보 · 주문 · 예약) · 알바(미니게임 + 구석 시세 + 폰 버튼) · 정산 카드 · 밤 장면 · 납부 관문(유품 선택) · 엔딩(지금 그대로).

## ⑥ 완료 기준 (각 줄 = 테스트 1개)
- [ ] 1. 1일차에 10배 포지션이 열리고, 증거금 합계 30만을 넘는 주문은 거절된다
- [ ] 2. 알바 미니게임이 도는 동안 종목 가격이 분 단위로 변한다
- [ ] 3. 알바 중 몰래 폰 보기로 포지션을 닫을 수 있고, 볼 때마다 일당이 15% 줄며, 들키면 그 칸 일당이 0이 된다
- [ ] 4. 예약 손절·익절이 자리를 비운 사이 가격이 닿으면 체결된다
- [ ] 5. 낮이 끝나면 정산 카드에 일당 · 포지션 손익 · 청산 여부가 한 번에 나온다
- [ ] 6. 밤 미래 장면이 그날 결과 4종(대박·손실·청산·평범)에 따라 다른 묶음에서 나온다
- [ ] 7. 7·14·21·28일 밤에 납부 관문이 뜨고 요구액이 주마다 커진다
- [ ] 8. 납부를 통과하면 유품 3개 중 1개를 고르고 증거금 상한이 오른다
- [ ] 9. 2주 연속 미납이면 28일 전에 원양어선 엔딩이 난다
- [ ] 10. 리포트만 따라 현물로 사는 봇의 매도 수익률 중앙이 +3~6% 다 (지금 +13%)
- [ ] 11. 2배↑ 포지션을 들고 알바 간 칸이 pro 판당 5회↑ · casual 3회↑ 다 (지금 경보 5% · 26% 판)
- [ ] 12. 28일 전에 끝나는 배드가 casual 15~40% · pro 5~20% 다 (지금 0%)
- [ ] 13. 대출 없이 깬 판이 pro 클리어의 30%↑ 다 (지금 0%)
- [ ] 14. 7일째 자산이 pro 가 casual 의 1.3배↑ 다 (지금 1.01배)
- [ ] 15. 원금이 처음 줄어드는 날 중앙이 7일째 이하다 (지금 26일째)
- [ ] 16. 밸런스 띠: 보통 pro 35~55% · casual 5~20% / 순한맛 casual 20~40% / 매운맛 pro ≤ 35%
- [ ] 17. 턴 모드 골든 24/24 · EditMode 전부 통과 · 저장 왕복 통과
- [ ] 18. 웹 빌드를 처음부터 엔딩까지 돌려 콘솔 에러 0건

## 만드는 순서 (단계마다 검수 후 다음으로)
1. **압박과 성장** — 주간 납부 관문 · 미납 규칙 · 유품 주간 보상 · 납부 막대 · 1일차 레버리지(증거금 상한) → ⑥-1·7·8·9·12·15
2. **읽어야 하는 시장** — 리포트 우위 축소 · 주식 변동성 · 예약 주문 · 칸 중간 사건 → ⑥-4·10·13
3. **하루 루프** — 알바 중 실시간 · 몰래 폰 보기 · 정산 카드 · 밤 결과 장면 · 기둥 연결 → ⑥-2·3·5·6·11·14
