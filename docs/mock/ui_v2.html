화면 개편 시안 3가지

같은 장면(집 · 장 보기 · 저녁 정산)을 세 방향으로 그렸습니다. 그림은 구조를 보여 주는 시안이라 차트 · 수치는 예시이고, 미래 그림과 배경은 게임의 실제 자산입니다. 방향을 고르시면 그 방향으로 전 화면을 바꿉니다.

지금 왜 불편한가 — 제가 본 원인

① 상자 넷이 서로 가림
상태판 · 선택지 상자 · 대사창 · 폰이 한 화면에 떠서, 폰을 열 때마다 서로 밀고 덮습니다.
② 제일 자주 하는 일이 제일 깊음
매매가 폰 → 탭 → 종목 → 주문 바. 차트는 폰 속 작은 그림.
③ 누를 곳이 세 군데
집 행동은 아래 퀵메뉴, 장소 행동은 가운데 상자, 매매는 폰.
④ 알바 한 번에 7단계
외출 → 지도 → 일하기 → (말 거는 사람) → 알바 → 설명 → 시작 → 안내.
⑤ 하루가 안 보임
오전 · 오후 · 밤 3칸 중 지금 어디고 남은 칸에 뭘 할 수 있는지 화면에 없음.
⑥ 작은 글자가 12줄
상태판에 줄이 너무 많아 정작 "이번 주 얼마 내야 하나"가 묻힘.
가 · 하루 계획판 + 트레이딩 데스크나 · 폰이 곧 화면다 · 3단 고정
