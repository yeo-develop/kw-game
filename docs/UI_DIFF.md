# UI — 고치기 전과 후 (2026-11-11)

> 왼쪽 = 고치기 전(배포본 81fd81b), 오른쪽 = 지금(167af10). 같은 화면을 나란히.
> **뼈대는 그대로다**: 왼쪽 위 상태판 · 가운데 선택지 상자 · 아래 대사창 · 오른쪽 폰이라는 배치와 색 · 글꼴 · 그림체는 안 바꿨다. 바뀐 것은 그 안의 정보 순서, 글자 크기, 색의 뜻, 조작 실수 방지, 숫자 표기다. 그래서 멀리서 보면 같아 보인다.

## 장 보기 (HUD · 선택지 · 퀵메뉴)

| 전 | 후 |
|---|---|
| ![전](screens/before/watch.jpg) | ![후](screens/watch.jpg) |

- 빚 · 현금이 "30,000,000원" → "3,000만원", 순자산 추가
- "이번 주 납부"가 작은 한 줄 → 큰 줄 + D-n 칩 + 막대("다 모음 · 내면 N 남음")
- 늘 떠 있던 "만기 목표: 빚 1,050만 이하…" → "목표: 빚 0원 = 클리어"가 위, 그 줄은 "못 갚아도:"로 작게
- 시계가 장중이면 빨강 → 흰색 + "장중" 칩 (빨강은 상승 전용)
- "폰 열기 / 닫기"와 "그만 보기"가 같은 모양으로 붙어 있음 → "그만 보기"를 떼어 놓음 (포지션이 있으면 두 번 눌러야 실행)
- 속도 줄에 키 안내(1·2·4 · Space), 퀵메뉴의 가짜 키 동그라미(장 · 미 · → · Z) 삭제
- 중독 막대 삭제(50 이상일 때만)

## 폰 — 시세

| 전 | 후 |
|---|---|
| ![전](screens/before/phone.jpg) | ![후](screens/phone_market.jpg) |

- 분석가 카드 4장이 폰의 40% 를 차지 → 한 줄 칩(이름 + 전적)
- 폰을 열면 선택지 상자가 HUD 를 가리고 퀵메뉴 오른쪽이 폰 뒤로 숨음 → 상자는 HUD 아래로, 퀵메뉴는 폰 왼쪽 안에 다 보임
- 등락 0 이 빨강 → 회색
- 상태줄의 깨진 네모(▮) → ●●●

## 차트 · 주문

| 전 | 후 |
|---|---|
| ![전](screens/before/order.jpg) | ![후](screens/chart_coin.jpg) |

- 주문창이 스크롤 아래에 있어 안 보임 → 폰 아래에 고정된 주문 바(금액 · 배율 · 롱/숏/진입)
- 체결 · 실패 메시지가 화면 맨 위 → 진입 버튼 바로 위 한 줄(실패하면 흔들림 + 거절음)
- 증거금 상한이 접힌 칸 안 → "상한 중 얼마 남음"이 늘 보임
- 오늘 받은 리포트 칩에 쓴 사람이 없음 → 분석가 이름 + 전적, 누르면 그 종목으로

## 저녁 정산 카드

| 전 | 후 |
|---|---|
| ![전](screens/before/settle.jpg) | ![후](screens/settle_card.jpg) |

- 일당 · 합계뿐 → 일당 · 매매 · 그 밖(리포트 · 사건 · 도박) · 합계 · 옮긴 돈 · 현금 A → B · 납부까지 남은 돈
- 합계가 실제 현금 변화와 달랐음 → 하루 장부에서 계산해 맞아떨어짐
- 이익이 초록(폰에선 빨강) → 이익 빨강 / 손실 파랑으로 통일, 초록은 현금 전용
- 정산 동안 HUD 가 숨겨짐 → 뒤에 HUD 가 보임
- "180,000원" → "18만원"
