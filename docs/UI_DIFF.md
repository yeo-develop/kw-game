# UI — 고치기 전 · 1단계 · 지금 (2026-11-11)

> 왼쪽 = 고치기 전(배포본 81fd81b) · 가운데 = 1단계(167af10, 뼈대는 두고 결함만 고침) · 오른쪽 = **지금(8723747, 화면 개편 (가))**.
> 1단계는 왼쪽 위 상태판 · 가운데 선택지 상자 · 아래 대사창 · 오른쪽 폰이라는 배치를 그대로 둔 채 정보 순서 · 글자 크기 · 색의 뜻 · 실수 방지 · 숫자 표기를 고쳤다. 그래서 멀리서 보면 같아 보였고("바뀐 게 없다"), 사용자가 "지금 UX가 너무 불편해"라고 해서 **배치 자체를 바꾼 것**이 오른쪽이다(기획서 `UI_V2.md`, 전체 화면 `SCREENS.md`).
