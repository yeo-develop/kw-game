첫 판 안내는 `?manual=1` 로 여는 점검 창에는 뜨지 않는다(`&tut=1` 을 붙이면 뜬다). 보통으로 연 창에서는 처음 한 번 뜨고, `?tut=0` 으로 끌 수 있다.

창은 뜨지 않는다. `check.js` 의 봇은 사람 흉내가 아니라 "내 집까지 가는지"만 본다(기한이 없어 엔딩까지 화면으로 몰면 너무 오래 걸린다 — 엔딩 길은 판 상태를 넣어 확인) — 재미와 난이도는 사람이 해 봐야 안다. 도구 한 번은 5분 안에 끝나게 `timeout 300` 을 걸어 돌린다.

화면은 1280×720 을 통째로 늘리고 줄인다(`ui.js` 의 `fit`). 맞춤 배율 f = min(창 너비 / 1280, 창 높이 / 720). f 가 1 이상이면 점 하나가 화면의 점(기기 픽셀) 정수 개가 되는 배율로 내려 맞추되 1배 아래로는 내려가지 않는다: n = floor(f × 기기 배율), 배율 k = max(1, n / 기기 배율). 1920×1080 · 기기 배율 1 이면 1배 그대로 가운데, 기기 배율 2 면 1.5배(점 하나 = 기기 점 3개), 남는 테두리는 같은 바둑판. 기기 배율이 1.25 · 1.5 처럼 정수가 아닌 화면(윈도우 125% 등)에서 k 가 1이면 점 하나가 기기 점 1.25 · 1.5개라 완전히 고르지는 않다 — 그 대신 무대가 창보다 훨씬 작아지거나, 창을 키웠는데 무대가 작아지는 일이 없다. f 가 1보다 작으면(작은 창) f 그대로 줄인다.

알려진 한계: 800×450 처럼 작은 창에서는 배치는 그대로지만 글자가 9px 안팎으로 작아지고 점이 고르지 않아 읽기 어렵다.
