# 롱잡고알바감 ~빚 3천 갚기 전엔 못 헤어져~ · 웹 컨셉 프로토타입 (v3.1)

`index.html` 한 파일로 돈다(인라인 CSS/JS, 외부는 Google Fonts만). `python3 -m http.server` 로 띄운 뒤 `http://localhost:8000/` 접속(파일을 바로 열어도 동작).

## 조작
- 클릭 / Space / Enter = 대사 넘기기·확인, 숫자키 = 메뉴·선택지·증강 카드 고르기
- 미니게임: 카페 1~4·0·Enter, 편의점·상하차 Space
- `D` = 디버그 패널 (현금 +1000만, 이자일 저녁으로, 멘헤라로, 빚 100만으로, 증강 +1)
- URL 옵션: `?fast=1` 연출 생략, `?seed=123` 시드 고정. 게임 로직 난수는 전부 시드 PRNG(Math.random 안 씀)

## 구조
- 하루 = 아침·오전·오후·저녁 4슬롯. 한 달 = 7일, 7일째 저녁 = 이자일(김사장). 최대 3개월.
- 집: 미래 스탠딩 + 대사창 + 오른쪽 '미래 폰'(시세 미니차트·보유금·이자 D-day / 증권 앱·지도·돈 땡기기·쉬기·기타).
- 지도: 증권사·은행(오전/오후), 카지노(오후/저녁), 경마장(오전/오후), 일하기·게임방·복권소(항상), 상점(오전~저녁). 장소에서 행동 1번 = 1슬롯. 폰(증권 앱·대출)은 슬롯을 안 쓴다.
- 슬롯이 넘어갈 때마다 전 종목 시세가 움직이고, 보유 포지션 손익 팝업(돈 환산 드립)·뉴스·코인 청산 판정이 나온다.

## 투자 (전부 가상 종목)
- 주식(오전·오후만): 갓성전자, 킹배터리, 국밥홀딩스, 곱버스 인버스2X. 앱 수수료 0.5%, 증권사 창구 0.1%.
- 코인(24시간): 빚트코인, 떡상코인, 멍멍코인(증강 해금, 최대 3배). 1~50배, 청산(증거금 90% 손실), 진입 수수료 0.1%×배율, 펀딩비 슬롯당 0.2%×배율, 진입한 슬롯엔 정리 불가.
- 시세: 종목별 변동성 + 지속되는 추세 + 시장 국면 + 뉴스 충격(시드 PRNG 랜덤워크).

## 증강 (16종, 시작 1개 + 이자 낼 때마다 1개, 리롤 1회)
실버: 분산투자러, 배당충, 인버스 장인, 청산 보험, 김프 장인, 알바 고인물, 사채 친화력, 긍정왕 미래 · 골드: 단타의 신, 존버충, 찌라시 구독, 증권사 VIP, 새벽 고래, 도박 중독 · 프리즘: 올인형, 밈코인 감별사

## 규칙 요약
- 빚 3,000만 원, 현금 30만 원으로 시작. 이자 = 현재 빚의 5%(사채 친화력 4%).
- 돈 땡기기(사채): 선이자 10%, 총 빚 한도 1개월차 3,600만 → 2개월차 4,300만 → 3개월차 5,000만. 이자일 부족분 대출도 같은 한도.
- 카지노(홀짝·하이로우 카드·슬롯·사다리)와 경마는 테이블 리밋이 있고(달마다 ×2 VIP 테이블), 한 번 가면 최대 3판.
- 이자를 못 내면 원양어선/갤 운영자 엔딩. 3개월 뒤 빚이 4,000만 넘게 남아도 같은 결말, 그 아래면 편의점 무한루프. 호감도 0 = 차단. 빚 0 = 클리어.
