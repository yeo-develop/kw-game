# 롱잡고알바감 ~빚 3천 갚기 전엔 못 헤어져~ · 웹 컨셉 프로토타입 (v3)

`index.html` 한 파일로 돈다(인라인 CSS/JS, 외부는 Google Fonts만). `python3 -m http.server` 로 띄운 뒤 `http://localhost:8000/` 접속(파일을 바로 열어도 동작).

## 조작
- 클릭 / Space / Enter = 대사 넘기기·확인, 숫자키 = 카드·선택지 고르기
- 미니게임: 카페 1~4·0·Enter, 편의점·상하차 Space
- 투자 리플레이 중 Space = 지금 청산
- `D` = 디버그 패널 (현금 +1000만, 이자일로 점프, 멘헤라로, 빚 100만으로)
- URL 옵션: `?fast=1` 연출 생략, `?seed=123` 시드 고정 (기본은 새 게임마다 시드가 바뀜)

## 규칙 요약
- 빚 3,000만 원, 현금 30만 원으로 시작. 한 달 = 10일, 10일째 밤 = 이자일(현재 빚의 5%).
- 하루: 아침 요약 → 낮(알바 / 홀짝·슬롯·사다리) → 밤(주식 MNQ / 코인 BTC / 꾸미기 / 쉬기·상환).
- 이자일: 현금 납부 / 부족분 대출 / 김사장과 홀짝 내기. 못 내면 게임 오버.
- 빚 상한 5,000만 원. 넘으면 즉시 게임 오버. 사채(+100만, +1,000만)는 선이자 10%를 떼고 받는다.
- 호감도 0이면 차단 엔딩. 멘탈이 '멘헤라'가 되면 카톡 탄막 이벤트가 나오고, 답장을 맞히면 호감도 +18, 틀리면 −11.
- 최대 3개월. 2개월째 이자일부터 "엔딩 보기"를 고를 수 있다.
- 엔딩: 클리어(빚 0, 꾸미기 반영) / 원양어선행 / 갤 운영자에게 팔려 감(갤 화제성 10 이상) / 편의점 야간 무한루프(시간 초과) / 차단당함(호감도 0).

## 차트 데이터
- `SAMPLE_CSV`(QQQ 분봉 → ×41.2 합성 MNQ)와 `SAMPLE_BTC_CSV`. 헤더는 `datetime,open,high,low,close,volume`.
- 매매할 때마다 120봉 구간을 시드로 골라 보여 준다. 구간의 시작점은 무작위이고, 절반 확률로 등락을 뒤집는다. 게임용으로 변동폭을 키운다(MNQ ×4, BTC ×1.8). 앞 20봉은 미리 보여 주고, 나머지 100봉을 10초 동안 재생한다.
- 실제 데이터로 바꾸려면 두 문자열을 같은 형식의 CSV로 통째로 교체하면 된다.

## 밸런스 (자동 플레이 기준)
- 알바만: 2개월 동안 이자는 내지만 빚은 3,000만 원에서 2,938만 원으로 거의 줄지 않는다 → 무한루프 엔딩.
- 도박·코인 몰빵: 대부분 1~2개월 안에 빚 상한에 닿아 원양어선·갤 운영자·차단 엔딩.
- 사채 1,000만 원을 빌려 홀짝·사다리에 걸고, 크게 따면 바로 상환: 시드 13개 중 4개가 1개월 3~6일째에 클리어.
